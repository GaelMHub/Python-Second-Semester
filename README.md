# Python-Second-Semester

> Collection of Python exercises and projects from my first semester — covering arithmetic, recursion, number logic, and basic algorithms.

---

## Programs

| File | Description |
|---|---|
| `bmi_calculator.py` | BMI calculator with sex-specific thresholds and diagnosis |
| `calculator.py` | Interactive console calculator with basic arithmetic operations |
| `fibonacci.py` | Generates the Fibonacci sequence up to N terms |
| `number_average.py` | Computes the average of a set of numbers entered by the user |
| `number_check.py` | Checks whether a number is positive, negative, even, or odd |
| `number_compare.py` | Compares two or more numbers and identifies the largest/smallest |

---

## Concepts Covered

| Concept | Programs |
|---|---|
| Arithmetic & Math | `calculator`, `number_average`, `bmi_calculator` |
| Recursion | `fibonacci` |
| Conditionals & Comparison | `number_check`, `number_compare` |

---

## Requirements

- **Language:** Python 3.x
- **OS:** Linux, macOS, or Windows
- **Dependencies:** None — standard library only

---

## How to Run

Clone the repository:

```bash
git clone https://github.com/GaelMHub/Python-Second-Semester.git
cd Python-Second-Semester
```

Run any program:

```bash
python filename.py
```

Example:

```bash
python bmi_calculator.py
```

## Notes

- All programs were written as part of first-semester coursework.
- Code is kept simple and readable — focused on learning, not optimization.
- Each file is self-contained and can be run independently.
